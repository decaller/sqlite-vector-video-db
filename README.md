# sqlite-vector Exploration

This project explores [sqlite-vector](https://github.com/sqliteai/sqlite-vector), an ultra-efficient SQLite extension for vector search.

## Features
- Brute-force nearest neighbor search (`vector_full_scan`)
- Quantized ANN search (`vector_quantize_scan`)
- WebAssembly support for browser-based vector search

## Files
- `index.mjs`: Node.js example script.
- `index.html`: Browser-based example (GitHub Pages ready).

## Usage

### Node.js
```bash
npm install
node index.mjs
```

### Browser
Open `index.html` in your browser.
